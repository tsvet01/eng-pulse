# Contract fixtures

These JSON files are generated by `cargo run -p pulse-core --bin fixtures` from the `pulse-core` crate's domain types (`Feed`, `Brief`, `RunReport`). They are consumed by the Swift and Kotlin contract tests as the canonical shape of the pipeline's JSON output. CI regenerates them on every run and fails the build if the output differs from what's committed here, so any change to `pulse-core`'s types must be accompanied by regenerating and committing these files.

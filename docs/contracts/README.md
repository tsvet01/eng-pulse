# Contract fixtures

These JSON files are generated by `cargo run -p pulse-core --bin fixtures` from the `pulse-core` crate's domain types (`Feed`, `Brief`, `RunReport`). `brief.json` includes extension fields to check lossless storage; `brief_minimal.json` covers omitted optional fields. The daily-agent mapper and API database/HTTP tests use both. The Swift CI job compiles `scripts/check-brief-contracts.swift` with the app's actual `InsightBrief` decoder. Android contract checks are deferred with the Android client. CI regenerates them on every run and fails the build if the output differs from what's committed here, so any change to `pulse-core`'s types must be accompanied by regenerating and committing these files.
